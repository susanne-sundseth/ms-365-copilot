# Using Copilot in PowerPoint

Instructor recommends using CP to first create a Word doc and then use the Word doc to create the slide deck.

Designer is part of CP so you can easily use it to change the slides.

## Lesson 61-62 Create presentation from scratch and with templates

Open a blank presentation or select a template and then specify a prompt to create text, images, vidoes, and speaker notes:

*   _Create a presentation about why coffee is the best thing to drink._

As with Word, a more succinct prompt will give you better results:

* _Create a presentation about why coffee is the best thing to drink, focusing on health benefits._

## Lesson 64 Add a slide

You can ask CP to add a slide about something generic but it might not include the points you want to make so ensure that you add those points into the prompt.

CP will take your points and make them more robust. Instead of your '_Coffee market is fragmented in Europe_', it will create something similar to '_The European coffee market is highly fragmented, with different preferences and trends across regions and countries_'.

The new slide will be added after the slide that is currently selected.

Per the instructor, you can also prompt it to add its own points from its LLM: _Add a slide detailing Europen consumer regulations. Add your own points to this._

## Lesson 65  Edit a slide

When you edit a slide, ensure that the speaker notes are also updated. Also, ensure that you click refresh when you want to edit a different slide so that your intended changes are applied to the correct slide.

Examples include:

* Edit this slide to include a bullet point about coffee nutrition
* Edit this slide to add an image of a farmer
* Add a relevant image to this slide
* Make the content on slide 2 more concise (or more informal, formal, casual, etc.)
* Add additional relevant content to this slide
* Change the content of this slide into bullet points
* Bold the word 'market'

## Lesson 66 Ask questions about a presentation

You can ask questions about PowerPoint documents as you can in Word; the response will include the related slides.

* Give me specific examples on how I can improve it this deck for a proposal
* Show key slides in the deck
* What are the key takeaways in the deck?
* What are the action items in the deck?
* If the doc is a proposal or similar => Are there any dates or deadlines in this deck?
* If you don't understand a term => What does 100% free trade mean on this slide?
* If you want/need additional info to include in the deck, you can ask some questions to generate conent or get inspiration  => What are the common factors influencing coffee conusmption in Europe? 

## Lesson 67 Summarize and organize

If you ask CP to summarize, it will show the main ideas of the presentation and which slide pertain to which idea.

If you ask CP to organzie, it will suggest a structure for you deck. Instructor used _organize deck_ but _suggest slide organzation_ worked better for me. For larger deck, you could ask to organize slides into sections and add slides for each section header.
